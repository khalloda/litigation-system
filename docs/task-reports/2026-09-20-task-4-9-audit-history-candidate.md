## What changed and why

- Administrator-only global history and contextual responsive drawers on existing
  record/child surfaces. Contacts and logos use their actual row IDs; matter
  parties/roles/lawyers, hearing attendees, work steps, POA lawyers, fee links,
  invoice allocations, staff aliases and account rows have contextual entries.
  Families without existing screens remain available globally; no unrelated
  attendance, lookup or reporting workflow was added.
- A shared typed historical projection preserves bigint IDs as strings and
  PostgreSQL microseconds as exact text. It distinguishes absent/null/empty,
  boolean/zero, redacted/truncated and unknown values without recovering secrets
  or inventing Access history. Current names never replace actor snapshots.
- UTC dates, historical actor/action filters and field/value search run server
  side. Approved Arabic normalization includes Arabic-Indic digits, never J→ق.
  Matching any event selects its complete relevant request group and marks
  matches; unrelated contextual events stay excluded. Request/correlation/session
  and immutable actor snapshots define a group—not merely time or actor.
- A fixed transactional audit watermark and signed account/session/filter/scope
  cursor provide deterministic group keyset pagination. Ordinary pages contain
  25 groups; groups are not split. Input/query/output limits refuse explicitly.
  The SQL gateway has an eight-second statement bound and a 20 MiB result bound;
  exports are limited to 10,000 groups/100,000 events, PDF to 2,000 events, and
  generated bytes to 20 MiB. There is no unrestricted all-history client payload.
- Retained immutable parent foreign keys and recorded before/after keys associate
  child history. Removed relationships remain visible. Covered-matter membership
  and matter-side fee-letter references are separate facts. No inferred invoice
  → matter association or reconstruction from current mutable field values.
- Deliberate same-origin POST produces ExcelJS XLSX or Playwright/Chromium PDF.
  Full selected results, scope, filters, UTC, exact times/IDs and watermark are
  included, not only the page. Excel strings cannot become formulas or links;
  ordered 12,000-UTF-16-unit chunks and UTF-8 Base64 companions preserve values
  that Excel XML cannot directly encode. A 300,000-row bound refuses overflow.
  PDF uses escaped HTML, bundled Noto fonts and branding, repeated table headings,
  page numbers, disabled JavaScript and denied external/file requests.
- Clear resets draft controls, actual results, URL and cursor on both bare and
  filtered URLs. Back/Forward restores state. Close/navigation invalidates stale
  requests. Native modal semantics, labels, focus containment/return, Escape,
  background scroll lock, responsive layout and visible focus are included.

## Export event semantics

One successful operation commits exactly one `export_completed` event, one
private receipt and one transactional audit-counter increment before returning
bytes. The event means **server generation completed**, never client receipt.
It binds actor, operation UUID, format, scope hash, watermark/counts and artifact
SHA-256. Existing events, business tables, accounts, ledger and all sequences
remain unchanged. A repeated operation returns 409 and adds no event; changing
the request under the same UUID is refused. A deliberately new UUID is another
export. Concurrent duplicate requests produce 200/409 and one event.

Generation/audit failure or revocation before commit returns no artifact and no
completion receipt. Abort before completion creates no false fact; abort after
the committed generation fact does not erase truthful evidence. PostgreSQL
commit and network delivery are not atomic. No `download_completed` is invented.
Views, filters, navigation, drawer operations and refused requests write nothing.
